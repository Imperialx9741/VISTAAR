# VISTAAR Customer Mobile Application

This is the initial Flutter Customer Mobile Application skeleton for VISTAAR.

## Getting Started

### 1. Prerequisites
Ensure you have the Flutter SDK installed on your machine. If it is not installed, follow the guide at [flutter.dev/docs/get-started](https://flutter.dev/docs/get-started).

### 2. Install Dependencies
Run dependency resolution in this folder:
```bash
flutter pub get
```

### 3. Run Static Analysis
Analyze code for issues or lint errors:
```bash
flutter analyze
```

### 4. Run Tests
To run the automated widget and unit tests, use:
```bash
flutter test
```

### 5. Run the Application
Run the app on a connected device/emulator:
```bash
flutter run
```
