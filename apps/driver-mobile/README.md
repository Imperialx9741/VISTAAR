# VISTAAR Driver Mobile Application

This is the initial skeleton for the VISTAAR Driver Mobile Application.

## Requirements
- Flutter SDK (>= 3.0.0 < 4.0.0)
- Dart SDK

## How to Install Dependencies
Run the following command inside this directory:
```bash
flutter pub get
```

## How to Run the Application
To run the application locally on an available development target, run:
```bash
flutter run
```

## How to Run Analyzer
To run static analysis and check for code issues:
```bash
flutter analyze
```

## How to Run Tests
To run unit and widget tests:
```bash
flutter test
```
